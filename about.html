My Treasure Map

이 앱은 모치즈키 도시타카의 《당신의 소중한 꿈을 이루는 보물지도》에서 아이디어를 얻은 디지털 보물지도 제작 도구입니다.

이루고 싶은 꿈을 담은 사진과 글을 한 장의 보드에 붙이고, 날마다 또는 달마다 새로 고치며, 완성된 보드를 HTML 파일로 발행해 간직하거나 공유할 수 있습니다.

사용법

  1. 날짜 고르기

    상단의 날짜를 고르면 그 날짜의 보드가 열립니다. 새 날짜에서는 빈 보드로 시작하거나, 가장 최근 보드를 복사해서 시작할 수 있어요.

  2. 보드 타이틀 꾸미기

    보드 위에 큰 제목이 나와요. 더블클릭해서 바로 고치고, 끌어서 옮기고, 오른쪽 아래 손잡이로 글자 크기를 조절하세요. 헤더의 제목을 클릭해도 바뀌고, ⋯ 메뉴에서 숨기거나 다시 보이게 할 수 있어요.

  3. 꿈 카드 만들기

    + Dream을 누르면 꿈 카드 폼이 열려요. 사진, 제목, 설명, 카테고리, 원하는 시기를 적고 Add to board를 누르세요. 사진을 보드로 끌어다 놓거나 Ctrl+V로 붙여 넣어도 사진이 담긴 폼이 열려요.

  4. Dreams 보관함

    상단 Dreams 탭은 아직 보드에 붙이지 않은 꿈까지 모아두는 보관함이에요. 검색·카테고리·시기순으로 찾고, Add to board로 지금 보드에 복사해 붙여요. 보드의 카드도 Save to Dreams로 보관함에 넣을 수 있어요.

  5. 배치하기

    끌어서 옮기고, 오른쪽 아래 동그라미를 끌어 크기를 조절하세요. 카드를 선택하면 바로 위에 작은 툴바가 떠서 Edit, Save to Dreams, Bring to front, Send to back, Delete를 할 수 있어요. 더블클릭하면 바로 수정할 수 있어요.

  6. 발행하기

    Keep 메뉴의 Publish as HTML을 누르면 보드가 HTML 파일 한 개로 저장됩니다. 사진이 파일 안에 들어 있고 발행 일시도 기록되어, 어디서든 열어볼 수 있어요.

  7. 아카이브에 간직하기

    지금의 보물지도를 남겨두고 싶을 때 Keep 메뉴의 Save to archive를 누르고, 미래의 나에게 한마디를 적어두세요. Archive에서 연도·월별로 돌아보며 어떤 꿈이 새로 생기고 어떤 꿈을 내려놓았는지 볼 수 있어요.

단축키와 조작

사진으로 꿈 카드 만들기Ctrl+V (Mac은 ⌘+V) 또는 사진 끌어다 놓기
선택한 카드 삭제Delete 또는 Backspace (글을 입력하는 중에는 동작하지 않아요)
선택한 카드 수정Enter 또는 더블클릭 (폼은 Esc로 닫기)
보드 타이틀 고치기더블클릭 (Enter 저장, Esc 취소)
선택 해제Esc 또는 보드의 빈 곳 클릭
사진 카드 비율 무시하고 크기 조절Shift를 누른 채로 크기 손잡이 끌기

저장에 대해

  • 모든 변경은 자동으로 저장됩니다. 상단 오른쪽에 Saving…과 Saved로 표시돼요.
  • 보드는 이 브라우저 안에만 저장되며, 서버로 전송되지 않습니다.
  • 브라우저가 다르거나 여는 주소가 다르면 저장 공간도 달라요. 한 곳에서 계속 사용하세요.
  • 브라우저의 사이트 데이터를 지우면 보드도 함께 지워집니다. 소중한 보드는 발행해서 파일로 보관하세요.
  • 처음부터 다시 하고 싶다면 오른쪽 위 ⋯ 메뉴를 쓰세요. Clear this board는 지금 보고 있는 날짜의 보드만, Delete all boards는 저장된 모든 보드를 지웁니다. 되돌릴 수 없어요. Dreams 보관함, 아카이브, 이미 발행한 HTML 파일은 그대로 남아요.
